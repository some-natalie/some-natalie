Earthquake dataset from USGS from magnitude 2.5+ for
- ~365 days from end of October 2025 to end of October 2026
- ~90 days back from near the end of October 2026
- ~30 days back from near the end of October 2026

Source - <https://earthquake.usgs.gov/earthquakes/search/>

Raw CSVs combined, deduplicated, and converted to geojson using Claude code

Used for random data product tests
