agent traces

Two sources in one ClickHouse. The ACP tap tees every JSON-RPC line between Zed and its agents into acp.messages; Langfuse records the LLM side — prompts, completions, tool spans, tokens and cost — in default.events_full. Browse reads the wire; the dashboards read Langfuse.

browse →Read sessions as transcripts, or drop to raw protocol messages. ACP wire. stats →Tool call counts, per-day volume, failures, and model spend by token. bash →Shell calls: duration, output read back, and which programs run. files →Which files were read, edited and written, and in which projects. secrets →Scan prompts and completions for credential material.
